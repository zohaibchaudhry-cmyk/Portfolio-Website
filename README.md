# My Personal Portfolio Website

This website was created for INFR3120 - Web and Scripting Programming Assignment 1.

The website uses HTML5 and CSS3 and includes four pages: Home, About Me, Projects, and Contact Me.

The purpose of this portfolio is to introduce myself, showcase my academic projects, and provide contact information.
## Responsive Design

I used fluid design and separate CSS files to make my website work on different screen sizes.

- Mobile (600px and below): mobile.css uses smaller margins and vertical navigation links.
- Tablet (601px–1024px): tablet.css uses medium margins and horizontal navigation.
- Desktop (1025px and above): desktop.css uses larger navigation spacing.

I chose these screen sizes to make the website easier to read and navigate on phones, tablets, and computers. I used media queries and did not use Flexbox.
## Gradients

I used two linear gradients in my website.

The first gradient is in the homepage header. It uses a 90-degree angle to create a transition between dark blue and light blue.

The second gradient is in the footer. It uses a 135-degree angle to create a diagonal colour transition.

I chose these gradients to keep the design consistent and make the website more visually appealing.
## Colour Scheme

I chose a blue colour scheme for my portfolio website.

- Dark blue (#305780) is used for headings and navigation.
- Light blue (#78a6d1) is used in the gradients.
- Light grey (#f5f7fa) is used for the background.
- Dark grey (#333333) is used for the text.

I chose these colours because they create a simple, consistent design that is easy to read.
## Code Documentation

I used HTML5 to create the structure of my four portfolio pages.

I used CSS3 to style the website, including the colours, headings, navigation, and gradients.

I used HTML5 form validation for the contact form and separate CSS files for responsive design.
